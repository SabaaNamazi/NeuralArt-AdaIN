🎨 NeuralArt — AI Neural Style Transfer
Transform ordinary photographs into artistic images using deep learning and AdaIN.
Python PyTorch Flask AdaIN Deep Learning

NeuralArt is a deep learning web application that combines the content of an image with the artistic style of another image using Adaptive Instance Normalization (AdaIN).
<img width="1366" height="768" alt="image" src="https://github.com/user-attachments/assets/2a27c464-43f6-4000-83a6-0fe8eb557def" />
Features
- Transfer artistic styles to photographs
- Upload content and style images
- Generate stylized images using the trained decoder
- Simple web interface built with Flask
